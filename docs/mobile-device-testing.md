# スマホ実機で動かしながら確認する（Expo Go）

パソコンで開発サーバーを動かし、スマホの **Expo Go** アプリで読み込むと、
コードを保存した瞬間にスマホの画面へ反映されます（ビルドやストア申請は不要です）。

## 1. 準備（最初の1回だけ）

1. スマホに **Expo Go** を入れます（App Store / Google Play で「Expo Go」を検索）。
2. パソコンとスマホを **同じ Wi-Fi** につなぎます。
   - スマホのモバイル通信（4G/5G）では届きません。
   - 会社や学校など、端末同士の通信が禁止されている Wi-Fi ではつながらないことがあります。
3. `apps/mobile/.env` に Supabase の URL とキーが入っていることを確認します（Web 版と同じ値）。
   `EXPO_PUBLIC_API_BASE_URL` は空のままか `http://localhost:3000` のままで大丈夫です。
   開発中は、スマホから見たパソコンの IP アドレスにアプリが自動で置き換えます。

## 2. 起動する

PowerShell を2つ開き、どちらも `shifton` フォルダで実行します。

```
# 1つ目: Web 版サーバー（写真の読み取り機能が使います）
pnpm dev:web
```

```
# 2つ目: スマホ版の開発サーバー
pnpm dev:mobile
```

2つ目の画面に **QR コード** が表示されます。

- **iPhone**: 標準のカメラアプリで QR コードを読み取り、出てきた「Expo Go で開く」をタップします。
- **Android**: Expo Go アプリを開き、「Scan QR code」から読み取ります。

初回は読み込みに少し時間がかかります。

## 3. 開発中の操作

- ファイルを保存すると、スマホの画面が自動で更新されます。
- 手動で再読み込みしたいときは、PowerShell の画面で `r` キーを押します。
- スマホを振るとメニュー（Reload など）が開きます。
- 止めるときは PowerShell で `Ctrl + C` を押します。

## つながらないとき

| 症状 | 対処 |
| --- | --- |
| QR を読んでも「Could not connect」などと出る | パソコンとスマホが同じ Wi-Fi か確認します。 |
| 初回起動時に「Windows セキュリティの重要な警告」が出た | 「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押します。閉じてしまった場合は、Windows の設定で Wi-Fi のネットワーク プロファイルを「プライベート」にし、ファイアウォールで Node.js を許可します。 |
| それでもつながらない | `pnpm dev:mobile --tunnel` で起動すると、インターネット経由でつながります（初回はツールの追加を聞かれるので `Y`）。ただしこの方法では、写真の読み取り機能（パソコンの Web 版サーバーを使う）は動きません。 |
| 写真の読み取りで「サーバーに接続できません」 | 1つ目の PowerShell で `pnpm dev:web` が動いているか確認します。`apps/web/.env.local` に `ANTHROPIC_API_KEY` も必要です（[shift-reader-setup.md](shift-reader-setup.md)）。 |
| `.env` を変えたのに反映されない | `Ctrl + C` で止めて、`pnpm dev:mobile --clear` で起動し直します。 |

## Expo Go で確認できないもの

Expo Go は開発用のアプリなので、アプリのアイコンや名前、ストア配信の確認はできません。
それらは、リリース前に EAS Build で「開発ビルド」を作って確認します。
