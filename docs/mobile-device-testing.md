# スマホ実機で動かしながら確認する（Expo Go）

パソコンで開発サーバーを動かし、スマホの **Expo Go** アプリで読み込むと、
コードを保存した瞬間にスマホの画面へ反映されます（ビルドやストア申請は不要です）。

## 1. 準備（最初の1回だけ）

1. スマホに **Expo Go** を入れます（App Store / Google Play で「Expo Go」を検索）。
2. パソコンとスマホを **同じ Wi-Fi** につなぎます。
   - スマホのモバイル通信（4G/5G）では届きません。
   - 会社や学校など、端末同士の通信が禁止されている Wi-Fi ではつながらないことがあります。
3. `apps/mobile/.env` に Supabase の URL とキーが入っていることを確認します（Web 版と同じ値）。
   `EXPO_PUBLIC_API_BASE_URL` は空のままか `http://localhost:3000` のままで大丈夫です。
   開発中は、スマホから見たパソコンの IP アドレスにアプリが自動で置き換えます。

## 2. 起動する（ダブルクリックだけ・Windows）

`shifton` フォルダの **`start-phone.cmd`** をダブルクリックします。

- Web 版サーバー（写真の読み取りに使います）が別のウィンドウで起動します。
- スマホ版の開発サーバーが起動し、**QR コード** が表示されます。

デスクトップに置いておくと便利です。`start-phone.cmd` を右クリックし、「その他のオプションを確認」→「送る」→「デスクトップ (ショートカットを作成)」を選んでください。

### 手で起動する場合

PowerShell を2つ開き、どちらも `shifton` フォルダで実行します。

```
# 1つ目: Web 版サーバー（写真の読み取り機能が使います）
pnpm dev:web
```

```
# 2つ目: スマホ版の開発サーバー
pnpm dev:mobile
```

2つ目の画面に **QR コード** が表示されます。

- **iPhone**: 標準のカメラアプリで QR コードを読み取り、出てきた「Expo Go で開く」をタップします。
- **Android**: Expo Go アプリを開き、「Scan QR code」から読み取ります。

初回は読み込みに少し時間がかかります。

## 3. 開発中の操作

- ファイルを保存すると、スマホの画面が自動で更新されます。
- 手動で再読み込みしたいときは、PowerShell の画面で `r` キーを押します。
- スマホを振るとメニュー（Reload など）が開きます。
- 止めるときは PowerShell で `Ctrl + C` を押します。

## 4. 遠くにあるスマホで確認する（別の Wi-Fi・モバイル通信でも OK）

家族や友だちの iPhone など、パソコンと同じ Wi-Fi にないスマホでも試せます。
パソコンの開発サーバーを、インターネット経由で一時的に公開する方法です。

### 起動する（ダブルクリックだけ・Windows）

`shifton` フォルダの **`start-phone-remote.cmd`** をダブルクリックします。

1. 初回だけ、公開用のツールが自動で入ります（数分かかることがあります）。
   - **cloudflared**: 写真の読み取りに使う Web 版サーバーを公開します（アカウント登録は不要です）。
   - **@expo/ngrok**: スマホ版の開発サーバーを公開します（Expo が使うツールです）。
   - 「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」を押します。
2. Web 版サーバーが別のウィンドウで起動します。
3. 「写真読み取りの接続先: https://～.trycloudflare.com」と緑の文字で表示されます。
4. しばらくすると **QR コード** と、**`exp://` で始まる URL** が表示されます。

### 遠くのスマホで開く

1. 相手の iPhone に **Expo Go** を入れてもらいます（App Store で「Expo Go」を検索）。
2. 画面に表示された **`exp://` で始まる URL** をコピーし、LINE やメールで相手に送ります。
   - コピーは、URL の部分をマウスでなぞって選び、右クリックするとできます。
3. 相手は、その URL を長押ししてコピーし、**Safari のアドレス欄に貼り付けて開きます**。
   「Expo Go で開きますか？」と出たら「開く」を押します。
   - 相手の手元に別の画面があるなら、QR コードの写真を送って iPhone のカメラで読んでもらってもかまいません。
4. 初回は読み込みに 1 分ほどかかります（同じ Wi-Fi のときより遅くなります）。

アプリにログインするアカウントは、相手用のものをアプリの画面から作ってもらうか、あなたのアカウントでログインしてもらいます。

### 注意

- **パソコンでウィンドウを開いている間だけ** 使えます。パソコンをスリープさせたり、ウィンドウを閉じたりすると、相手のスマホからも使えなくなります。
- 起動するたびに URL が変わります。毎回新しい URL を送ってください。
- URL を知っている人なら誰でも開けるので、知らない人には送らないでください（写真の読み取りはログインした人しか使えません）。
- 終わるときは、`start-phone-remote.cmd` のウィンドウで `Ctrl + C` を押し、Web 版サーバーのウィンドウも閉じます。
- 次に同じ Wi-Fi で試すときは、いつもどおり `start-phone.cmd` を使ってください（そのほうが速いです）。

### 遠くのスマホでうまくいかないとき

**「ngrok tunnel took too long to connect」と出る**
ngrok 側の混雑です。少し待ってから、ウィンドウを閉じて開き直してください。ウイルス対策ソフトが止めている場合もあります。

**「Web 版サーバーを公開できませんでした」と出る**
パソコンがインターネットにつながっているか確認して、開き直してください。

**cloudflared が自動で入らない**
PowerShell で `winget install --id Cloudflare.cloudflared` を実行し、終わったら PowerShell を閉じてから `start-phone-remote.cmd` を開き直します。

**写真の読み取りで「サーバーに接続できません」**
Web 版サーバーのウィンドウで `pnpm dev:web` が動いているか確認します。Web 版サーバーのウィンドウを閉じた場合は、`start-phone-remote.cmd` から起動し直してください。

## つながらないとき

**QR を読んでも「Could not connect」などと出る**
パソコンとスマホが同じ Wi-Fi か確認します。

**初回起動時に「Windows セキュリティの重要な警告」が出た**
「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押します。閉じてしまった場合は、Windows の設定で Wi-Fi のネットワーク プロファイルを「プライベート」にし、ファイアウォールで Node.js を許可します。

**それでもつながらない**
下の「遠くにあるスマホで確認する」の方法（`start-phone-remote.cmd`）なら、Wi-Fi に関係なくインターネット経由でつながります。

**写真の読み取りで「サーバーに接続できません」**
1つ目の PowerShell で `pnpm dev:web` が動いているか確認します。`apps/web/.env.local` に `ANTHROPIC_API_KEY` も必要です（[shift-reader-setup.md](shift-reader-setup.md)）。

**`.env` を変えたのに反映されない**
`Ctrl + C` で止めて、`pnpm dev:mobile --clear` で起動し直します。

## Expo Go で確認できないもの

Expo Go は開発用のアプリなので、アプリのアイコンや名前、ストア配信の確認はできません。
それらは、リリース前に EAS Build で「開発ビルド」を作って確認します。
