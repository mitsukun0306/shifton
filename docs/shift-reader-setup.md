# シフト表読み取り機能のセットアップ

写真・スクリーンショットからシフトを読み取る機能は、Anthropic 社の AI（Claude）の画像認識を使います。
使うには **Anthropic の API キー** が必要です。所要時間はおよそ10分です。

> 先に [Supabase のセットアップ](supabase-setup.md) を済ませておいてください。

## しくみ

```
スマホ / ブラウザ ──画像──▶ Web 版のサーバー（/api/shifts/read-image）──▶ Claude（画像認識）
                ◀─シフトの候補─┘
確認画面で修正 ──▶ Supabase に登録
```

- API キーは Web 版のサーバーだけが持ちます。アプリ（スマホ・ブラウザ）には入れません。
- 読み取りはログイン中のユーザーだけが使えます。
- 画像はサーバーに保存しません。読み取りのために Anthropic の API に送られます。
- 読み取り結果はすぐには登録されず、確認画面で直してから登録します。

## 1. API キーを作る

1. https://platform.claude.com を開き、アカウントを作成してログインします。
2. **Billing**（請求）でクレジットを購入します（最初は最低額で十分です）。
   - 料金は使った分だけかかります。読み取り1回あたり **数円〜10円程度** が目安です（画像の大きさや表の量で変わります）。
   - 使いすぎが心配な場合は、**Limits** で月の上限額を設定できます。
3. **API Keys** を開き、**Create Key** でキーを作ります。名前は `shifton` などで構いません。
4. 表示された `sk-ant-` で始まるキーをコピーします。**この画面を閉じると二度と表示されない** ので、すぐに次の手順で貼り付けてください。

> API キーはパスワードと同じです。GitHub やチャットに貼らないでください。
> もし漏れてしまったら、同じ画面ですぐにキーを削除（Disable / Delete）して作り直してください。

## 2. Web 版にキーを設定する

`apps/web/.env.local`（Supabase の設定を書いたファイル）に1行追加します。

```
ANTHROPIC_API_KEY=sk-ant-（コピーしたキー）
```

Web 版を再起動（Ctrl + C で止めて `pnpm dev:web`）すると、シフト一覧の上に
**「写真・スクショからシフトを読み取る」** ボタンが表示され、使えるようになります。

## 3. スマホ版から使う（開発中）

スマホ版は、パソコンで動いている Web 版のサーバーに画像を送って読み取ります。

1. パソコンの IP アドレスを調べます。
   - Mac: システム設定 > Wi-Fi > 接続中のネットワークの「詳細」 > IP アドレス
   - Windows: 設定 > ネットワークとインターネット > Wi-Fi > プロパティ > IPv4 アドレス
2. `apps/mobile/.env` に追加します（`192.168.0.10` の部分を調べた IP アドレスに変えます）。

   ```
   EXPO_PUBLIC_API_BASE_URL=http://192.168.0.10:3000
   ```
3. Web 版を `pnpm dev:web -- -H 0.0.0.0` で起動します（同じ Wi-Fi のスマホからつながるようにするため）。
4. スマホ版を再起動し、「読み取り」タブから写真を撮る・画像を選ぶと読み取れます。

> 本番公開後は、公開した Web 版の URL（例: `https://shifton.example.com`）を設定します。

## うまく読み取れないとき

- 表全体が写るように、正面から明るい場所で撮影してください。影や斜めの撮影は苦手です。
- 複数人のシフト表では、**シフト表に書かれているとおりの名前**（例: 「佐藤」）を入力してください。
- 「早番」「A」などの記号は、表の中に時間の説明（凡例）があれば時間に置き換えます。説明がない記号は読み取れないため、確認画面のあとで手入力してください。
- 1か月分の大きな表は、半月ずつなど分けて撮ると精度が上がります。

| 表示されるメッセージ                             | 確認すること                                                                                       |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| 読み取り機能が未設定です                         | `apps/web/.env.local` の `ANTHROPIC_API_KEY` を確認し、Web 版を再起動                              |
| API キーを確認してください                       | キーのコピー漏れ・削除済みのキーでないかを確認                                                     |
| 読み取りが混み合っています                       | 少し待ってから再度お試しください                                                                   |
| 読み取りサーバーに接続できませんでした（スマホ） | `EXPO_PUBLIC_API_BASE_URL` の IP アドレス、同じ Wi-Fi か、Web 版を `-H 0.0.0.0` で起動したかを確認 |
